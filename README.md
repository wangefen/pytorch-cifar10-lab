# PyTorch CIFAR-10 Training Lab

## 项目目标

从零实现一套面向 CIFAR-10 的 PyTorch 图像分类训练工程。

计划包括：

- PyTorch Tensor 与自动求导
- CIFAR-10 数据加载与数据增强
- SimpleCNN
- 训练、验证和测试
- YAML 配置管理
- 日志与 CSV 记录
- Checkpoint 保存与断点恢复
- ResNet-18 模型迁移
- 实验对比与结果绘图
- 向联邦学习客户端本地训练迁移
